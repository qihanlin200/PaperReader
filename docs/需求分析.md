# 个人论文阅读器需求分析

- 版本：v0.6（交互与流式输出更新版）
- 日期：2026-11-03
- 状态：Python 首版开发迭代中；需求与实际验收状态分别记录

## 1. 产品目标

面向个人使用的 macOS 与 Windows 跨平台论文阅读器，将论文导入、原文阅读、AI 分析、连续追问、选区翻译与个人学习记录整合到简洁的分栏界面中。

核心流程：导入论文 → 阅读与高亮 → AI 分析 → 针对概要或选中文字追问 → 添加批注与笔记 → 本地保存并回顾。

## 2. 已确认的首版范围

| 项目 | 需求 |
| --- | --- |
| 平台 | 首版支持 macOS 与 Windows，核心功能及本地数据格式保持一致 |
| 本地导入 | PDF 文件，不支持其他文件格式 |
| 网站导入 | arXiv 等主流论文网站；其他网站清单待明确 |
| 原文阅读 | PDF 连续滚动、触控板与鼠标滚轮跨页阅读、文本选择、简洁分栏 |
| AI 分析 | 生成论文概要，支持围绕概要继续追问；所有 AI 返回内容流式显示并支持 Markdown |
| 选区追问 | 选中文字，右键发起追问 |
| 翻译 | 选中单词、句子或段落，右键翻译，支持中英文 |
| 阅读标注 | 高亮、批注、个人笔记 |
| 学习记录 | 保存 AI 分析内容及个人注释；建议同时保存问答记录 |
| 数据保存 | 本地存储，无云端存储或同步需求 |
| AI 接入 | 可配置 API 基础地址、模型名称和密钥，支持模型连接测试；首版使用 OpenAI 兼容接口 |

首版不包含全文翻译、OCR 扫描件识别、Linux 版本和云端同步。扫描型 PDF 可以提示其缺少可选文本，不承诺提供选区翻译、追问和全文分析。

以下“建议”是待确认的设计方案，不代表用户已经确认。

## 3. 论文导入与资料库

### 3.1 本地 PDF

支持文件选择和拖拽导入。建议将 PDF 复制到本地资料库，避免源文件移动后无法阅读；保留标题、作者、年份、导入时间和阅读进度，并允许修正元数据。

检测重复文件，遇到损坏、加密或无法提取文字的 PDF 时说明原因，保留已有学习记录。

### 3.2 网站导入

arXiv 纳入首版范围，建议支持其论文摘要页及 PDF 链接，下载 PDF 后进入同一本地阅读流程。保存来源地址及可获取的论文标识、版本信息。

其他主流网站应按用户常用来源列出具体名单，逐项确认可接受的链接类型与公开全文获取方式。“支持主流网站”不等于支持任意网页。对无法获取全文、需登录或无访问权限的来源，提示改为本地 PDF 导入，不绕过访问限制。

网络用于论文下载及已配置的云端模型 API 调用；论文下载、AI 推理和学习记录存储属于不同的数据流。应用不需要建设云端资料库。

### 3.3 建议的资料库能力

论文列表、标题搜索、最近阅读及阅读进度。标签、收藏、批量导入和版本管理可后续确认优先级。

## 4. 原文阅读与个人标注

### 4.1 PDF 阅读

原文采用连续纵向滚动预览，支持触控板像素滚动和鼠标滚轮自然跨页，无需在页尾手动点击下一页。保留上一页、下一页及缩放操作；页码随滚动更新并保存阅读页，缩放尽量保持页内相对位置。

为保持流畅，仅按需渲染可视区域及邻近页，释放远离可视区域的位图。更新概要、问答或标注时不应重复渲染整篇 PDF，不应无故清除当前选区。复杂 PDF 的渲染耗时和真实触控板惯性手感需在两端实测，不以自动化检查替代性能验收。

文本选择按鼠标拖动的起止词确定范围，支持水平、反向和快速拖动；松开鼠标时确认终点，选中文字显示蓝色底纹。右键可复制、翻译、追问、高亮或添加批注。右键无选区时提示先选择文字。选择与标注坐标应适配缩放和旋转页面，操作绑定实际选区所在页，而非仅绑定当前页码。暂不支持跨页选择及扫描件文字选择。

文本搜索、自由页码输入、目录导航和 AI 引用点击定位仍为后续完善项；已有标注可定位到对应页。

双栏排版、跨页段落及公式可能影响文字提取，需保留原始 PDF 供核对，并对解析不完整的情况提示。

### 4.2 高亮、批注与个人笔记

- 高亮：对选区添加高亮，可删除；建议支持颜色选择。
- 批注：对选区或高亮添加文字说明，可编辑、删除和跳回对应原文。
- 个人笔记：每篇论文有独立笔记，可持续编辑，不强制绑定选区。
- 保存：上述内容自动存入本地，重启后恢复，AI 重新分析不得覆盖个人内容。

建议标注先保存在资料库中，不修改原始 PDF。是否需要将高亮和批注写入可被其他阅读器识别的 PDF，另行确认。

选区关联信息应包含论文、页码、原文摘录及定位信息，避免只保存文字而无法定位。更换 PDF 后应检测关联是否仍有效。

## 5. AI 分析与追问

### 5.1 概要分析

建议包含研究问题、背景、核心贡献、方法、实验结果、局限及术语解释。默认中文可作为初始方案，输出深度待确认。

分析应标明实际覆盖范围，关键结论尽量附可定位的原文依据，区分论文陈述与 AI 推断。未成功解析全文时，不得声称完成全文分析。保留已有分析，避免误操作覆盖学习成果。

### 5.2 围绕概要连续追问

以当前论文建立会话，支持针对概要进一步提问。回答结合原文和必要的历史上下文；没有原文依据时明确说明。建议问答自动保存，并支持复制与回到原文。

长论文问答需能查找相关原文，不能只把概要当作完整论文依据。建议在本地解析与检索原文，将回答所需的相关片段发送给模型 API；具体上下文策略待技术评估。

### 5.3 选中文字右键追问

交互流程：选中文字 → 右键“针对所选内容提问” → 追问栏显示原文引用和问题输入框 → 输入问题并提交 → 显示回答及依据。

选区上下文应包含论文、页码和必要的相邻文本；跨栏操作后仍保留选区引用。用户应能核对本次引用内容。选区必须与问题一并保存，便于回顾。引用选区用于明确问题所针对的原文，不等同于高亮或批注；允许提交前清除引用，成功回答后清除本次引用。清除引用不删除原文或已有标注。

建议将“解释这段话”等快捷问题作为后续便捷功能，不代替自由输入。

### 5.4 所有 AI 输出流式展示

概要、追问答复、选区翻译和模型连接测试均使用流式响应，收到文本片段后及时更新界面，不等待完整结果才显示。网络任务在后台执行，阅读、滚动与笔记输入保持可操作。

流式草稿与所属论文关联，切换论文时不能混入其他论文的内容。模型配置在发起请求时固定，本次结果不得因中途配置变化被错误标注。服务端异常、连接中断和输出未完整结束时应提示，不把部分输出标记为完整结果。

概要与问答的部分结果加中断标识后本地保存；未收到任何文本时保留已有概要，问题输入保留以便重试。翻译中断时保留弹窗中已收到的译文。完整结果和导出保留原始 Markdown。

## 6. 选中文字翻译

选中单词、句子或段落后，通过右键“翻译所选内容”触发。请求开始即打开独立弹窗展示原文和译文，支持复制，避免占用固定的第四栏。译文逐段流式显示并按 Markdown 渲染；请求期间防止误关闭，结束后可关闭。

支持中英文方向，建议默认英文译中文，中文译英文。词语翻译应结合论文语境，段落翻译尽量保留公式、术语和引用编号。

全文翻译及保留排版的译文 PDF 不在首版范围。当前译文不自动保存，可复制至个人笔记；首版分析、追问和翻译共用模型配置。单独收藏译文和按任务配置不同模型可后续讨论。

## 7. 本地学习记录

必须持久保存 AI 分析、高亮、批注和个人笔记；建议同时保存问答、选区引用、元数据和阅读位置。译文默认是否保存待确认。

内部存储负责可靠恢复及关联，导出格式负责独立阅读与迁移，两者不必相同。建议采用结构化本地资料库保存记录与原文件，首选 Markdown 导出学习记录，HTML/PDF 导出可后续增加，最终格式仍可调整。

自动保存需显示状态，失败时明确提示；应用重启后恢复已保存内容。删除论文时应明确影响范围，不应无提示地删除原文件和学习记录。

需补充确认：资料库位置、备份恢复方式、整体迁移，以及导出是否包含问答、标注摘录和原文页码。

## 8. 界面布局

采用可收起的论文列表和三个可调宽度的主栏：

| 原文预览栏 | AI 分析栏 | 追问答复栏 |
| --- | --- | --- |
| PDF、缩放、页码、选区、高亮与批注入口 | 结构化概要、原文引用 | 会话、选区引用、问题输入与回答 |

支持通过分栏手柄调整宽度、收起和恢复单栏。布局记忆与窄窗口标签切换仍待完善。建议个人笔记和批注列表以可切换面板呈现，避免同时增加过多固定分栏。

选区右键菜单至少包含：复制、翻译所选内容、针对所选内容提问、高亮、添加批注。可补充工具栏入口，提升功能可发现性。

### 8.1 分栏手柄交互

- 点击手柄：收起左侧栏，再次点击恢复。
- Shift + 点击手柄：收起或恢复右侧栏，包含最右侧问答栏。
- 长按约 0.45 秒：手柄变蓝并进入调整状态，左右拖动自定义栏宽。
- 长按后松开不触发收起；未达到长按时长的快速拖动也不应误触收起。
- 收起后手柄仍可操作，恢复时参考收起前的栏宽；至少保留一个可见栏。
- 手柄悬停显示操作提示；这里的“收起”仅影响分栏，不最小化整个应用。

### 8.2 Markdown 编辑与显示

概要、问答、译文、选区引用及批注详情统一支持 Markdown 展示，包括标题、列表、引用、表格、行内代码和代码块。个人笔记及批注使用多行 Markdown 源码编辑并提供预览；追问使用多行纯文本框，不显示 Markdown 标签与提示，通过发送按钮提交，换行不立即发送。

流式返回尚未闭合的 Markdown 结构可随后续文本重新排版；不同问答消息分别解析，避免某条未闭合的代码围栏影响其他消息。保存、重新打开和导出时保留 Markdown 源文。

模型地址、模型名称、密钥、链接与文件路径属于普通配置输入，不做 Markdown 排版；PDF 保持原版预览，论文列表、页码和状态提示属于导航信息。Markdown 显示禁用内嵌 HTML、图片资源读取和链接导航。不承诺 LaTeX 数学公式排版。

### 8.3 模型设置弹窗

默认宽度 860px，最小宽度 720px，允许用户调整窗口，输入框随窗口伸展，避免可用编辑区域过窄。任意长度的地址仍通过输入框横向滚动编辑，不要求所有内容始终同时可见。

提供“测试模型连接”按钮，使用当前输入的地址、模型和密钥，无需先保存；发送简短测试请求，不附论文内容，提示可能产生少量费用。后台流式显示响应，结束后显示成功或明确失败原因。测试期间禁用重复触发与保存，防止关闭弹窗导致回调失效；测试不会自动保存配置。

## 9. 云端模型 API、本地存储与隐私

论文原文件、元数据、AI 分析、问答、高亮、批注和个人笔记保存在本地，不要求云端资料库、账号系统或多设备同步。允许调用云端大模型 API 完成概要分析、追问和选区翻译；本地模型不是首版必需能力。

本地存储不代表处理过程完全离线。调用模型时，所需的论文文本、选区、问题或会话上下文会传送给配置的服务商。服务商是否保留请求、保留多久及是否用于训练取决于其服务条款和配置，应用不能以“本地保存”承诺第三方零留存。

建议本地完成 PDF 解析与相关片段检索，按任务发送必要上下文；概要分析可能需要分段发送大部分或全部论文文本。界面应说明 AI 请求会发送的内容类型，由用户主动触发分析、追问或翻译，不在导入后默认自动上传全文。

模型设置支持 API 基础地址、模型名称和 API Key，并提供连接测试。首版支持 OpenAI Chat Completions 兼容接口及 SSE 流式响应，不直接支持所有厂商原生协议；各任务共用一组配置。API Key 使用操作系统安全存储（macOS 钥匙串、Windows 系统凭据机制），不写入普通记录、日志或导出文件。

应支持请求取消、超时提示、失败重试和已有结果复用。鉴权失败、限流、余额不足、网络中断或上下文超限时保留已完成内容，不进行无上限自动重试。费用与实际用量依服务商计费，是否需要用量统计和预算提醒待确认。

断网时仍可阅读本地论文、查看历史分析与问答、编辑高亮批注和笔记；依赖云端 API 的新分析、追问及翻译提示需要联网。后台请求不得阻塞阅读和笔记输入。

## 10. 首版验收场景

1. 本地导入含可选文本的 PDF，能够阅读、搜索及恢复阅读位置。
2. 使用 arXiv 摘要页或 PDF 链接导入论文并保存来源；失败链接有明确提示。
3. 原文、AI 分析和追问答复可三栏显示，并可调整宽度或收起。
4. 生成结构化概要，明确分析范围，关键依据可定位到原文。
5. 围绕概要连续追问，正确保留当前论文上下文。
6. 选中文字右键追问，输入区带有所选原文引用，回答与引用一并保存。
7. 选词、句子或段落均可通过右键完成中英文翻译。
8. 添加、编辑或删除高亮、批注与笔记，重启应用后仍可正确恢复并定位。
9. 重启后 AI 分析及已保存问答可回顾，重新分析不覆盖个人笔记。
10. 下载失败、解析失败、模型 API 请求失败或保存失败不会破坏已有学习内容。
11. 配置云端模型 API 后可完成分析、追问及选区翻译；API Key 不出现在普通日志和导出内容中。
12. 断网后仍可阅读本地论文、回顾历史结果及编辑个人记录，新 AI 请求提示联网；资料库恢复不依赖云端存储。

13. 模型设置弹窗可伸展输入框，未保存的配置可执行流式连接测试，不发送论文内容。
14. 概要、问答、翻译及连接测试均在结果完成前逐段显示返回文本；断流后正确标注部分结果。
15. Markdown 标题、列表、表格及代码块正确渲染，历史结果和导出保留原文；笔记、问题、批注可多行编辑及预览。
16. 使用鼠标滚轮和触控板连续跨页阅读，页码正确更新，按需渲染，不因 AI 内容更新而跳页或清除选区。
17. 同高度水平拖动、快速拖动和反向拖动均可选中文字；右键动作携带正确的选区原文与页码。
18. 点击手柄可收起恢复左侧栏，Shift + 点击操作右侧栏；长按后可调宽，长按释放不误收起，至少保留一栏。

测试样本应覆盖中英文、双栏排版及含公式图表的可选文本 PDF；OCR 与全文翻译不纳入验收。

## 11. 仍需确认的问题

| 优先级 | 问题 | 当前建议或约束 |
| --- | --- | --- |
| 重要 | 实际使用的模型服务及模型？ | 用户可配置，需支持 Chat Completions 与 SSE 流式输出 |
| 必须 | macOS 与 Windows 的最低系统版本和 CPU 架构？ | 两端分别确认兼容范围及安装包要求 |
| 重要 | API 费用预算、用量统计与提醒要求？ | 由用户主动触发任务，复用已有结果 |
| 必须 | 除 arXiv 外具体需要哪些论文网站？ | 按常用来源逐项列出，避免泛化承诺 |
| 重要 | 概要输出语言和精细程度？ | 建议中文、结构化概要 |
| 重要 | 高亮和批注是否需要写回 PDF？ | 建议先保存在资料库，保持原文件不变 |
| 可后置 | 是否需要自动保存或收藏选区翻译？ | 当前问答自动保存，译文可复制至笔记 |
| 重要 | 本地资料库位置、备份及导出要求？ | 建议资料库可迁移，优先 Markdown 导出 |
| 可后置 | 标签、收藏、书签、深浅色和快捷键？ | 按个人阅读习惯确定 |

## 12. 跨平台要求

- 首版同时面向 macOS 和 Windows；Linux、移动端及浏览器版本暂不纳入。
- 两端均支持 PDF 与 arXiv 导入、三栏阅读、可配置云端模型 API、选区翻译与追问、高亮、批注、笔记及本地持久化。

## 16. 高清预览与触控板缩放补充

原文预览应适配 Retina/高 DPI 屏幕，按物理像素渲染，放大后重新生成清晰位图，不仅拉伸旧图。采样倍率与阅读逻辑尺寸分离，选区和标注位置保持正确。支持触控板双指捏合及 Ctrl+滚轮缩放，保留工具栏缩放；普通双指滚动仍跨页阅读。缩放范围当前为 50%–400%，以手势中心尽量保持原文位置。渲染需限制内存并保留按需加载；PDF 内嵌低清图片不承诺细节增强。真实触控板、高 DPI、多屏和 Windows 手势应分别验收。

## 17. 缩放交互优化与标注撤除

缩放过程中不得每帧重建整篇页面或清空现有位图，应复用现有图像即时反馈，手势停顿后恢复高清渲染，保持原文锚点。性能验收需检查连续捏合时的闪屏、响应延迟和结束后清晰度。

支持在原文已有标注上右键，以及标注面板操作取消高亮和删除批注，二者独立撤除并保存；取消高亮不删除批注内容，删除批注不取消高亮，全部移除整条标注则移除全部。无选区时仍可命中已有标注。重启后撤除结果保持，其他页和不相交标注不受影响。

## 33. 双模式分析与可配置输入预算



学习工作台顶部可选“快速概要”或“精读报告”，点击生成。快速概要在预算内读取全文，长文选择开头、结尾及重点章节页节选。精读报告切分全部可提取文本，逐段分析，再分层汇总，保留总报告与分段记录。两种结果独立本地保存，精读报告随学习记录导出。全部请求流式返回，显示当前段进度，完成段立即保存；失败保留部分结果，暂不支持自动断点续跑或取消。

模型设置中“最大输入长度”独立保存，默认50000字符，范围4096–2000000，包含提示词、历史与用户文本。字符不等于Token，需要按实际服务容量设置并预留输出。所有分段及汇总遵守上限；追问按剩余预算选择原文，必要时缩减旧对话，问题本身超限则提示。实现位于 services/analysis.py，无新增依赖。

重新生成已有报告时，确认提示明确显示论文标题及具体报告类型，说明只覆盖该报告，另一报告及笔记、标注、历史问答保留；使用中文“取消 / 重新生成”按钮，默认取消，不使用笼统的“当前模式”或 Yes/No。

原生窗口标题栏也应采用应用级深色外观，与深色工作台协调；保留系统窗口操作，不依赖用户将整个 macOS 系统切换深色。

各分栏的滚动条默认隐藏，仅鼠标进入对应滚动区域或滚动条区域时显示，移出隐藏，不改变内容可用宽度，不影响鼠标滚轮、触控板及拖动操作。
