# 新增 PaperReader 主题

每个主题绑定一位阅读助手。主题与助手一起切换，深色主题和「无情的阅读机器」是默认组合。新增时，先向用户收集下列信息；已给出的内容可以直接沿用，没想好的字段可以交给开发者设计。

## 给用户的输入模板

```text
主题名称（必填）：
绑定角色的显示名（必填）：
视觉方向（必填）：主色、背景色、氛围，或一张参考图
回答语气（必填）：希望怎么说、如何称呼用户，也可以填「中性、无角色口吻」
示例回答（可选）：一句或一小段符合角色的示例
避免的表达（可选）：不使用的称呼、口头禅或表达方式
图片素材（可选）：头像、顶部横幅、品牌图标，或交给开发者设计
角色副标题（可选）：例如「妙木山 · 大蛤蟆仙人」
```

## 主题包结构

在 `paperreader/themes/` 下新增一个目录。目录名是持久化的主题 ID，可用小写字母、数字、连字符和下划线。发布后保留 ID，展示名称可以单独更新。应用启动时发现主题，设置页自动列出有效主题。

```text
paperreader/themes/example/
  theme.json
  voice.md        # 可选，缺省时使用中性表达
  style.qss       # 可选，追加到共用控件样式
  document.css    # 可选，追加到 Markdown 文档样式
  avatar.png      # 可选，绑定角色头像
  banner.png      # 可选，顶部横幅
  brand.svg       # 可选，品牌图标
```

`theme.json` 只要求展示名称与绑定角色名称。可按需声明其他资源。

```json
{
  "name": "示例主题",
  "assistant": {
    "name": "示例助手",
    "voice": "voice.md",
    "avatar": "avatar.png",
    "tagline": "角色副标题"
  },
  "colors": {
    "#0b1019": "#181616",
    "#66ddda": "#e8a57e"
  },
  "stylesheet": "style.qss",
  "document_css": "document.css",
  "banner": "banner.png",
  "pdf_paper": "#30271b",
  "pdf_ink": "#f3dfba",
  "banner_background": "#181616",
  "brand_icon": "brand.svg",
  "header_height": 96,
  "panel_inset": 1,
  "heading_background": "#514d32",
  "question_placeholder": "向示例助手提问，或引用原文…"
}
```

- 所有清单中的文件路径相对于主题目录。QSS 可以用 `__THEME_DIR__` 引用包内资源。参考现有 `dark` 和 `naruto` 主题。
- `colors` 映射共用样式中的基准色；`warm_surfaces` 可选，用于把未映射的蓝灰色转成暖灰。也可用 `arrow` 指定包内下拉箭头。
- 横幅默认显示整张图。可用 `banner_crop` 指定纵向裁切范围，按 0 到 1 的比例填写上下边界。
- `pdf_paper` 和 `pdf_ink` 指定 PDF 预览的纸面与文字色，缺省为白底黑字。
- `voice.md` 只描述本主题的表达方式。论文证据、引用和忠实翻译要求由应用处理。
- 请求发起时固定助手。新回答保存主题 ID 和发起时的署名；旧回答没有署名时沿用当前助手名。清单无效或已选主题缺失时可回到默认深色主题。

新增后检查设置页能选择该主题，切换后外观和下一条请求同步改变，重启能恢复选择，并验证旧回答的署名和导出。PyInstaller 随应用收集整个主题目录。
