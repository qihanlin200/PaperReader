# 首版验证记录

日期：2026-11-03。环境：macOS arm64，Python 3.9.6，PySide6 6.10.3，PyMuPDF 1.26.5。

## 已通过

- 一键安装脚本成功创建虚拟环境并安装 requirements。
- Python 源码编译检查。
- unittest 3 项：PDF 哈希去重及存储恢复、arXiv/直接链接识别、模拟 OpenAI 兼容 API 协议。
- Qt offscreen 窗口启动、生成 PDF 渲染、矩形选词、高亮保存、选区追问引用和个人笔记写入。

## 尚未验证

Windows 实机、真实显示器交互和高 DPI、真实 API 凭据与模型返回质量、实际 arXiv 下载、系统密钥库读写、长篇复杂排版论文。offscreen 冒烟测试不能替代用户交互验收。

## 已知首版边界

参见根目录 README。特别是没有任务取消、可点击 AI 引用和全文搜索；模型可配置仅指 Chat Completions 兼容接口。阅读选区为矩形选词，不是原生 PDF 光标选择。概要长文会截断并提示分析范围。

## 模型设置与流式概要更新

5 项 unittest 全部通过，新增 SSE 分段解析及提前断流验证。Qt offscreen 检查通过：弹窗宽度、异步连接测试反馈、流式概要更新与落盘。测试使用模拟接口，没有调用真实收费服务。Windows 实机仍待验证。

## 全部 AI 流式与 Markdown 更新

7 项自动化测试通过，包含新增长文编辑/预览、问答流式更新与持久化、译文流式弹窗和问答断流部分保存。测试通过模拟模型完成，真实 API 与 Windows 实机仍待验证。

## 连续滚动更新

8 项测试通过。新增 20 页 PDF 场景，验证滚动跨页、邻近页按需渲染、离屏位图释放、选区批注页码及缩放位置保持。Qt offscreen 未模拟真实触控板惯性，滚动手感及复杂 PDF 性能仍需实机确认。

9 项自动化测试通过。新增 Qt 鼠标按下/松开事件验证同高度水平拖动、快速拖动与反向选择，并检查右键菜单动作信号携带原文。仍需实机验证触控板操作。

11 项测试通过。新增模拟 DPR=2 的物理分辨率/逻辑尺寸检查、高清采样下选词坐标检查及原生捏合事件放大检查。测试中发现 QLabel 默认图像路径可能按当前设备密度重采样，已改用显式位图绘制保留高清源。仍需实际 Retina 屏及触控板、Windows 实机确认。
