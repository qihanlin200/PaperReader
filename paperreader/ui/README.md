# 界面模块

`window.py` 管理论文列表、原文、分析/笔记/批注标签与问答栏；利用 QThreadPool 执行网络任务，通过信号回到主线程更新数据。首版同时仅一个后台任务，结束前不允许退出。

`pdf.py` 将 PyMuPDF 页面渲染为 Qt 图像，通过矩形与单词包围盒相交提取选区；右键动作交由主窗口处理。高亮坐标使用 PDF 坐标保存，缩放时重绘，不修改原文件。

笔记防抖保存 500ms，切换论文及退出时立即保存。批注可编辑删除，双击定位。需人工验证跨栏选区、系统密钥库及不同平台显示缩放。概要、问答、译文与选区引用使用 Markdown 渲染。

## 模型设置与流式概要

模型设置默认宽度 860px，最小宽度 720px，输入框随窗口扩展。连接测试使用未保存的输入发送简短请求，不包含论文；后台执行并显示成功或错误，测试期间阻止关闭弹窗。概要通过 Qt 信号逐段更新，切换论文时按论文隔离草稿。完成后保存；断流后将已收到文本标为部分结果保存，没有收到文本则保留旧概要。

## Markdown 分析显示

`markdown.py` 使用 Qt 内置 GitHub Markdown 渲染标题、列表、表格和代码块，无新增依赖。流式草稿、完成结果和历史概要均使用同一渲染器，存储及导出仍保留原始 Markdown。禁用内嵌 HTML、图片资源加载和链接导航，避免模型内容读取本地文件或自动发起网络请求。`MarkdownEditor` 为笔记、问题和批注提供源码编辑及实时预览，保存原始源码。不包含 LaTeX 公式排版。未闭合的代码围栏等结构会随流式内容到达重新排版。

问答草稿按论文隔离，各条消息分别解析 Markdown，避免未闭合代码围栏影响其他消息。翻译弹窗流式展示，任务期间阻止关闭。连接测试同样使用 SSE，以验证接口流式兼容性。配置字段不做 Markdown 渲染。

## 连续 PDF 预览

`ContinuousPDF` 使用原生 QScrollArea 接收触控板与滚轮事件，为各页预留固定尺寸，按需分批渲染可见及邻近页，释放离屏位图。页码根据滚动位置更新，本地阅读位置防抖保存。选区信号携带真实页码，避免跨页可见时批注绑定到错误页。刷新分析/标注不会清空阅读选区或重新栅格化 PDF。当前单页渲染在主线程，极复杂页面仍可能短暂停顿。

## 选区修复

改为按拖动起止位置定位词序范围，避免水平拖动零高度导致空选区；鼠标释放时确认终点，兼容未收到移动事件的快速拖动。选中文字逐词蓝色高亮，支持反向拖动。页面单词信息渲染时缓存，选择与批注绘制适配旋转页坐标。空选区右键提示先选择文字。暂不支持跨页选择。

## 分栏手柄操作

点击手柄收起左侧栏，再次点击恢复；Shift+点击收起或恢复右侧栏（包括最右问答栏）。长按 0.45 秒，手柄变蓝后左右拖动调整宽度；长按松开不收起。短暂拖动不会意外触发收起。至少保留一个可见栏。手柄悬停可查看提示，相关实现位于 `paperreader/ui/splitter.py`。

## 高清预览与触控板缩放

PDF 按屏幕像素密度渲染，普通屏至少 1.5 倍采样，Retina 按实际 DPR 采样，避免低分辨率位图放大。单页最多约 2400 万像素以控制内存，逻辑尺寸及选区坐标不随采样倍率变化。支持 macOS 原生捏合、Qt pinch 手势及 Ctrl+滚轮缩放，范围 50%–400%；手势按 32ms 合并，尽量保持手势中心处的原文位置。普通双指滚动继续用于阅读。源 PDF 内嵌低清图片无法恢复原始细节。真实设备手势及跨屏效果仍需实测。

## 缩放流畅度与取消标注

缩放时复用已有页面和位图做即时预览，不重建整篇页面；停顿约 180ms 后按可视区域重新渲染高清图像并替换。缩放中可能暂时稍模糊，结束后恢复高清，复杂页最终渲染仍可能耗时。

在已有标注上右键，或选中相交文字后右键，可“取消高亮”或“删除批注”。两者独立：取消高亮保留批注，删除批注保留高亮；两者均移除后清理记录。标注面板提供相同操作，以及删除整条标注。已有资料兼容，新操作自动保存本地。

双击 PDF 中的单词可直接选中并显示蓝色底纹，随后右键复制、翻译、追问、高亮或添加批注；双击空白处清除选区。按 PDF 提取的词边界选择，支持缩放和旋转页面；扫描件无可选文字。

## 深色科技风界面

`theme.py` 统一 Fusion 样式、深蓝灰调色板、青色强调色和 Markdown 内容样式。所有窗口、菜单、输入、滚动条与弹窗共享主题，不新增第三方依赖。`window.py` 采用顶部品牌/当前论文、左侧导入与论文列表、原文预览、学习工作台（分析/笔记/批注）、论文追问结构。无选区时隐藏引用区，按钮保持现有业务方法连接。PDF 保持原始纸张颜色，新增适宽按钮，工具栏百分比随手势缩放同步。`splitter.py` 使用对应深色手柄配色。保留系统窗口标题栏以支持原生移动、最小化与关闭。

AI 分析使用独立阅读排版：正文 13px、行距 150%，一级/二级/三级标题为 18/16/14px；标题上间距 14px、下间距 6px，段落间距 9px，列表项间距 4px。通过 QTextBlockFormat 显式设置，避免 Qt Markdown 忽略 CSS 间距。只调整分析视图，原始 Markdown 与导出不变。
