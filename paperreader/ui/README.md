# 界面模块

`window.py` 管理论文列表、原文、分析/笔记/批注标签与问答栏；利用 QThreadPool 执行网络任务，通过信号回到主线程更新数据。首版同时仅一个后台任务，结束前不允许退出。

模型设置页底部左侧提供“导入配置”和“导出配置”，右侧保留取消与保存。导出时可选择是否明文包含 API Key；导入后可检查和修改配置，点击保存才写入本地。未打开论文时点击追问发送，追问框直接提示先导入或打开论文，不会发起模型请求，输入的问题仍保留。

`work_rail.py` 绘制随主题配色变化的图标工作栏，宽度固定为 48px。顶部是论文列表开关，底部是系统设置；按钮保持 38px 点击区域，图标缩为 21px，并居中对齐。按钮仅显示图标，提供悬停提示及辅助功能名称。工作栏位于分栏外侧，论文列表收起后仍可操作。论文列表默认展开；点击工作栏最上方的书本图标可收起，之后点击可恢复到收起前的分栏布局，反复切换不会改变其他栏宽。顶部只显示主题品牌标识和 PaperReader 名称，原生窗口标题显示“PaperReader · 读起来不烧心”；论文标题位于“原文预览”旁，过长时省略显示，悬停可查看完整标题。主题横幅、图片和动画仍使用原顶部区域。

左栏顶部用搜索框代替“我的论文”标签：输入标题或来源关键词时实时筛选，多个关键词需全部命中，清空输入恢复列表。搜索框右侧同高对齐的“＋”弹出三个入口：本地论文导入、网页链接导入、创建分组。两个导入入口沿用工作栏原图标；创建分组使用文件夹加号图标。创建弹窗最小宽度 620px。论文列表缩小左侧内边距，让标题更靠左。分组标题直接显示在论文列表内，单击可折叠或展开，折叠状态在本次窗口的列表刷新后保留；搜索时自动展开匹配结果。论文右键“移动到分组”更改归属。分组标题右键可修改名称、置顶或删除。删除时可只删分组并把论文移回“未分组”，也可连同组内论文及其学习记录彻底删除。收藏论文在各组内置顶。底部本地保存提示已移除。搜索与分组整理不会关闭当前已打开的论文。

论文标题可以拖到任意分组标题或该组内的论文行以移动；空的“未分组”仍显示为放置目标。Ctrl+单击可挑选多篇论文，Shift+单击可选中连续论文，再一起拖入分组；macOS 同时支持实体 Control 键和 Command 键多选。快捷键选择时不会切换正在阅读的 PDF。拖拽时截取被拖动论文行作为跟随鼠标的预览，多选时叠加篇数标记，并保持按下位置作为预览锚点；目标分组会高亮，靠近列表上下边缘时自动滚动。拖入已折叠的分组后自动展开并定位新位置；仅更新论文与分组的关系，不改变论文文件或学习记录。收藏星标不可作为拖拽源。

按住分组标题拖动，可将整个分组放到另一分组标题的上半部或下半部；插入线显示放置位置。也可拖到目标分组的论文行，放在该分组后。分组内论文会随分组一起移动，单击标题仍可折叠。跨越置顶分组边界时会同步调整置顶状态，以维持置顶分组排在前面。“未分组”固定在末尾，不参与分组排序。

`pdf.py` 将 PyMuPDF 页面渲染为 Qt 图像，通过矩形与单词包围盒相交提取选区；右键动作交由主窗口处理。高亮坐标使用 PDF 坐标保存，缩放时重绘，不修改原文件。

笔记防抖保存 500ms，切换论文及退出时立即保存。批注可编辑删除，双击定位。需人工验证跨栏选区、系统密钥库及不同平台显示缩放。概要、问答、译文与选区引用使用 Markdown 渲染。

## 模型设置与流式概要

模型设置默认宽度 860px，最小宽度 720px，输入框随窗口扩展。连接测试使用未保存的输入发送简短请求，不包含论文；后台执行并显示成功或错误，测试期间阻止关闭弹窗。概要通过 Qt 信号逐段更新，切换论文时按论文隔离草稿。完成后保存；断流后将已收到文本标为部分结果保存，没有收到文本则保留旧概要。

## Markdown 分析显示

`markdown.py` 使用 Qt 内置 GitHub Markdown 渲染标题、列表、表格和代码块，无新增依赖。流式草稿、完成结果和历史概要均使用同一渲染器，存储及导出仍保留原始 Markdown。禁用内嵌 HTML、图片资源加载和链接导航，避免模型内容读取本地文件或自动发起网络请求。`MarkdownEditor` 为笔记、问题和批注提供源码编辑及实时预览，保存原始源码。支持常见 LaTeX 数学公式子集。未闭合的代码围栏等结构会随流式内容到达重新排版。

问答草稿按论文隔离，各条消息分别解析 Markdown，避免未闭合代码围栏影响其他消息。翻译弹窗流式展示，任务期间阻止关闭。连接测试同样使用 SSE，以验证接口流式兼容性。配置字段不做 Markdown 渲染。

## 连续 PDF 预览

`ContinuousPDF` 使用原生 QScrollArea 接收触控板与滚轮事件，为各页预留固定尺寸，按需分批渲染可见及邻近页，释放离屏位图。页码根据滚动位置更新，本地阅读位置防抖保存。选区信号携带真实页码，避免跨页可见时批注绑定到错误页。刷新分析/标注不会清空阅读选区或重新栅格化 PDF。当前单页渲染在主线程，极复杂页面仍可能短暂停顿。

## 选区修复

改为按拖动起止位置定位词序范围，避免水平拖动零高度导致空选区；鼠标释放时确认终点，兼容未收到移动事件的快速拖动。选中文字逐词蓝色高亮，支持反向拖动。页面单词信息渲染时缓存，选择与批注绘制适配旋转页坐标。空选区右键提示先选择文字。暂不支持跨页选择。

## 分栏手柄操作

点击手柄收起左侧论文列表，再次点击恢复；固定工作栏始终显示。收起和展开只在相邻栏之间转移宽度，反复切换保持原布局。Shift+点击收起或恢复右侧栏（包括最右问答栏）。按住手柄左右移动超过 6 像素即可调整宽度。长按后松开不会收起。至少保留一个可见分栏。手柄悬停可查看提示，相关实现位于 `paperreader/ui/splitter.py`。

## 高清预览与触控板缩放

PDF 按屏幕像素密度渲染，普通屏至少 1.5 倍采样，Retina 按实际 DPR 采样，避免低分辨率位图放大。单页最多约 2400 万像素以控制内存，逻辑尺寸及选区坐标不随采样倍率变化。普通鼠标滚轮和触控板双指滑动用于上下阅读；按住 Ctrl 滚动鼠标滚轮可缩放。触控板捏合支持原生、Qt pinch 和 Ctrl+滚轮事件，缩放响应增益为 1.5，范围 50%–400%；每次手势增量立即作用于页面，尽量保持手势中心处的原文位置。同一手势仅采用最先收到的有效缩放事件。源 PDF 内嵌低清图片无法恢复原始细节。真实设备手势及跨屏效果仍需实测。

## 缩放流畅度与取消标注

缩放时复用已有页面和位图进行快速绘制，不重建整篇页面；原生手势结束后约 90ms、普通缩放停顿约 180ms 后由独立进程重绘可视页面并替换高清图像。手势未发送结束事件时按 500ms 空闲间隔恢复。已提取的页面文字在缩放后复用。缩放中可能暂时稍模糊，复杂页最终重绘仍可能耗时。

系统设置 → 常规设置的“论文背景 → 跟随界面主题”使用 `ThemeSwitch` 滑动开关，默认开启。开关以滑轨颜色、圆点位置及“已开启 / 已关闭”文字区分状态。关闭后 PDF 使用原始白底黑字，切换界面主题不会重新着色 PDF；重新开启后按当前主题重绘。设置保存在本地 `config.json` 的 `pdf_follow_theme` 字段。学习工作台的阅读按钮与分析模式下拉框固定为 36 像素高，在各主题中垂直对齐。

在已有标注上右键，或选中相交文字后右键，可“取消高亮”或“删除批注”。两者独立：取消高亮保留批注，删除批注保留高亮；两者均移除后清理记录。标注面板提供相同操作，以及全部移除整条标注。已有资料兼容，新操作自动保存本地。

双击 PDF 中的单词可直接选中并显示蓝色底纹，随后右键复制、翻译、追问、高亮或添加批注；双击空白处清除选区。按 PDF 提取的词边界选择，支持缩放和旋转页面；扫描件无可选文字。

## 深色科技风界面

`theme.py` 统一 Fusion 样式、深蓝灰调色板、青色强调色和 Markdown 内容样式。所有窗口、菜单、输入、滚动条与弹窗共享主题，不新增第三方依赖。`window.py` 采用顶部品牌、固定图标工作栏、可折叠论文列表、带论文标题的原文预览、学习工作台（分析/笔记/批注）、论文追问结构。论文列表行距略收紧。无选区时隐藏引用区，按钮保持现有业务方法连接。PDF 的“校准”按钮保持原适配栏宽功能，工具栏百分比随手势缩放同步。`splitter.py` 使用对应深色手柄配色。保留系统窗口标题栏以支持原生移动、最小化与关闭。

默认「星空主题」沿用 `dark` 内部 ID。`WorkspaceBackground` 将主题包的 `starfield.png` 按窗口尺寸绘制成一张连续背景；主题专属 QSS 使面板微透，让星点只作为暗纹出现，PDF 页面与主要阅读文本仍使用高对比度底色。切换到其他主题时停止绘制星空，切回时重新使用同一张资源图。macOS 和 Windows 打包配置都会收集主题目录。

AI 分析使用独立阅读排版：正文 13px、行距 150%，一级/二级/三级标题为 18/16/14px；标题上间距 14px、下间距 6px，段落间距 9px，列表项间距 4px。通过 QTextBlockFormat 显式设置，避免 Qt Markdown 忽略 CSS 间距。只调整分析视图，原始 Markdown 与导出不变。

## 从 AI 分析发起追问

在 AI 分析中选中文字后右键“针对所选内容提问”，右侧会显示引用并定位到问题输入框；输入问题后发送，回答继续流式展示。引用明确标为 AI 分析而非原文页码，提醒模型结合论文核实。问答连同引用本地保存，成功回答后清除本次引用。

引用卡片右上角圆形 × 用于清除本次引用并隐藏卡片，不再显示独立清除按钮；不影响问题输入和历史问答。

追问输入区为多行纯文本框，不显示 Markdown 编辑/预览标签及提示；回车或点击发送按钮提交，Windows 用 Ctrl+回车换行，macOS 用 Option+回车换行。AI 答复继续支持流式 Markdown。笔记和批注编辑不受影响。

## 输入框内发送与多模型配置

追问使用纯文本输入，底部内嵌模型选择与发送按钮，文字编辑区域预留底部空间。模型设置可新增、命名、编辑、删除多个配置，每项独立保存 API 地址、模型名与系统密钥库账号；保存后可在输入框内切换。至少保留一项配置，旧配置兼容到默认项并沿用原密钥。当前选择也供概要与翻译使用；请求期间禁用切换，已有历史不改写。切换模型不清除问题和引用。`services/profiles.py` 管理配置结构，`ui/composer.py` 管理内嵌控件布局。

模型选择框右侧增加 30px 独立按钮区、分隔线及青色下拉箭头；整个选择框仍可点击展开，悬停加强边框，应用内所有模型下拉框统一显示。

## 问题导航与历史会话

论文追问标题中间显示居中问题导航点，点击跳到对应问答、悬停查看问题。数量过多时隐藏溢出，可用触控板左右滑动（也支持滚轮）查看。右侧“新建会话”开始独立对话，“历史”菜单查看当前论文的会话、时间和问题数量并切换。旧问答兼容迁移到首个会话；每个会话独立保存上下文，导出包含全部会话。请求期间暂不允许新建/切换，避免流式回复写错会话。新建和切换会清除未发送输入及引用，旧问答不会被删除。实现位于 `ui/questions.py` 与 `services/sessions.py`。

问答角色标签“你 / AI”使用独立的左对齐段落，清零缩进及左边距；消息仅拼接 Markdown 转换后的正文，避免嵌套完整 HTML 导致标签受到前一条列表/引用样式影响。

数学公式支持 `$…$`、`$$…$$`、`\(…\)` 与 `\[…\]`，通过 `ui/math_render.py` 本地 MathText 渲染并缓存；不加载外部图片，不执行 LaTeX 程序。流式尚未闭合及不支持的公式保留源码。代码块与金额不按公式处理；复杂 LaTeX 宏/环境暂不支持。更新环境需重跑安装脚本安装 matplotlib，原始学习记录及导出仍保留 LaTeX。

公式图像显式使用透明背景及浅灰蓝文字，消除默认白色底块。Markdown 表格统一左对齐（含单元格），表头深蓝灰、正文与面板同色，边框使用主题灰蓝；分析、问答与预览共用渲染规则。

右击顶部的问题导航点，在菜单中选择“添加到笔记”，将当前选中问题（含引用）及助手回答的 Markdown 源文追加到当前论文笔记末尾，前置 Markdown 分割线 `---`，保留已有及未自动保存的编辑内容。每次选择均追加，不记录已添加状态，允许重复添加；历史会话也可使用。流式尚未完成时不显示入口。

## 批量导入与移除

本地 PDF 导入支持多选，逐个处理并去重；单个文件失败会汇总提示，其余正常导入。论文列表右键“移除论文…”弹窗提供取消、仅从列表移除、彻底删除。仅移除保留记录，重新导入相同 PDF 可恢复。彻底删除应用资料库中的 PDF 副本及该论文全部笔记、概要、会话、问答、标注和阅读记录，清理内存草稿与公式缓存；源文件、已导出文件、外部备份和云端 API 服务商记录不在删除范围。删除当前论文时停止阅读保存定时器，避免旧记录复活；后台请求运行时暂不允许移除。彻底删除为应用级逻辑删除，不承诺存储介质取证擦除。

移除确认弹窗加宽至至少 720px，并用布局留白保证宽度；两种操作的标题和按钮加粗，彻底删除使用警示色并注明不可恢复。

移除弹窗标题为“确定移除《标题》？”，仅从列表移除与彻底删除（不可恢复）说明标题显式加粗；取消、仅从列表移除、彻底删除三个按钮作为同组右对齐。

## 快速概要与精读报告

学习工作台顶部可选“快速概要”或“精读报告”，点击生成。快速概要在预算内读取全文，长文选择开头、结尾及重点章节页节选。精读报告切分全部可提取文本，逐段分析，再分层汇总，保留总报告与分段记录。两种结果独立本地保存，精读报告随学习记录导出。全部请求流式返回，显示当前段进度，完成段立即保存；失败保留部分结果，暂不支持自动断点续跑或取消。

模型设置中“最大输入长度”独立保存，默认50000字符，范围4096–2000000，包含提示词、历史与用户文本。字符不等于Token，需要按实际服务容量设置并预留输出。所有分段及汇总遵守上限；追问按剩余预算选择原文，必要时缩减旧对话，问题本身超限则提示。实现位于 services/analysis.py，无新增依赖。

重新生成报告确认框明确显示论文标题与“快速概要/精读报告”名称，说明覆盖范围，按钮使用“取消 / 重新生成”，默认取消。

网站导入使用可伸展输入弹窗，默认宽820px、最小760px，按钮为“导入/取消”。模型输入长度 QSpinBox 与文本字段共享边框、内边距和高度，内嵌编辑器取消重复内边距。

通过 Qt 应用级 Dark color scheme 设置原生窗口标题栏外观，再应用深蓝灰调色板与 QSS。保留 macOS 红黄绿按钮、标题栏拖动、缩放和系统菜单，不修改系统全局外观。需 PySide6 6.8+。

滚动条默认透明隐藏，鼠标进入对应滚动区域时显示滑块、移出隐藏；保留滚动条尺寸以避免布局跳动，触控板、滚轮及拖动功能保持。问题导航仍使用原有无滚动条横向滑动。

滚动条显隐改用 `ui/scrollbars.py` 的应用事件过滤器：进入滚动区域显示，移出隐藏，整条滚动条透明度切换，不依赖样式表的父级 hover 匹配。恢复圆角滑块主题样式，保留尺寸避免挤动内容。

双栏论文拖选先从起点附近多行的空白间隔识别分栏，将词序限定在起点所在栏，避免同行另一栏误选。支持左右栏、反向拖选及旋转页；未检测到可靠栏间距时保留单栏选择逻辑。栏识别结果按选区起点缓存。

追问输入框与答复框、引用卡片统一左右边缘，外层水平及底部边距为0，上方间距8px；模型选择与发送按钮仍在框内保留内边距。

## 按需加载论文

启动和刷新列表仅查询 paper_index 中的标题、来源与ID，不反序列化全文学习记录、不打开PDF。点击后按ID加载该篇PDF、笔记、报告与历史问答。已有资料库首次升级通过SQLite建立一次元数据索引，后续增删改同步维护；旧编号标题延迟到打开时识别。导入去重按ID查询，不再扫描所有记录；重命名与移除显式读取对应记录，避免用列表元数据覆盖完整内容。

## 首次打开论文的公式处理

窗口中的分析、笔记预览及历史问答使用后台公式渲染：先显示正文及公式源文本，单线程工作队列完成字体初始化和公式图片后再更新当前内容，Qt 主线程只处理文档排版。切换论文时旧任务不会恢复旧正文；流式更新期间合并待处理工作，已生成公式复用缓存。`MarkdownBrowser` 独立使用时仍默认同步，窗口显式启用异步。打包应用复用按应用所在路径区分的本地公式字体缓存，避免 PyInstaller 每次启动的临时缓存重建；无新增依赖。

## 模型请求状态与提交输入

`request_status.py` 提供 AI 分析、论文追问共用的可折叠状态区。任务提交后显示模型、等待首段内容、累计用时；开始流式输出后显示接收状态与累计字符数，精读报告另外记录每段与汇总阶段。等待指示条和秒数持续更新，但不代表服务端的真实完成百分比。成功后自动折叠，点击标题可再次展开；失败保留展开状态供排查。日志仅保留在本次窗口内，不记录 API 密钥、提示词或回答正文，无新增依赖。

追问任务被接受后立即清空问题和引用，不等到生成结束。完成时保留用户新输入的下一条草稿。请求失败且当前输入为空时恢复原问题，避免丢失；输入检查失败或任务未提交时保留原输入。

状态记录直接嵌入 AI 分析和追问的 Markdown 内容框内，随正文滚动，不再占用框外的独立区域。点击框内状态标题可展开或折叠，完成后保留一行摘要。状态更新复用已渲染正文与公式资源，不重新请求模型或重新生成公式；日志以转义文本插入。

请求状态按论文ID隔离；分析另外按快速概要/精读报告区分，追问另外按会话ID区分。后台任务的状态归属在发起时固定，切换页面只切换可见状态，后续流式片段、计时和完成回调不能将状态写入当前正在浏览的另一篇论文。切回原论文可查看本次运行中的状态记录，彻底删除论文时一并清理。

论文列表单击或双击标题均打开论文，双击不再修改名称。通过论文右键菜单“修改论文标题…”进入重命名，窗口默认宽860px、最小宽760px，并提供保存/取消；保存同步更新列表、顶部标题及资料库。

## AI 分析目录与强调标签

AI 分析标签右上角的「目录」按钮打开可搜索的浮动目录，标题来自当前已渲染的 Markdown。流式生成期间目录会合并刷新新增标题；点击条目跳到对应位置。目录不占用常驻栏宽，切换到笔记或批注时隐藏。`outline.py` 实现弹层，`markdown.py` 提取标题；`math_render.py` 修正 `**【推断】**正文` 一类紧贴中文的加粗标签，同时保留原始 Markdown 和代码内容。
