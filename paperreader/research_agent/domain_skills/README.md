# 领域研究技能

每个领域技能独立占一个目录，包含 `manifest.json` 和 `instructions.json`。路由时只读取
`manifest.json` 的简短描述；选中技能后才加载该目录的完整指令。

内置技能位于本目录。用户技能保存在 PaperReader 用户数据目录下的
`skills/domains/<id>/`；同名用户技能优先于内置技能。目录名与 `manifest.json` 的 `id`
须一致，格式为小写字母开头，后接小写字母、数字或下划线。

技能库可查看全部当前技能。领域技能支持新建、编辑、删除，以及 ZIP 导入和导出。
编辑内置领域技能会在用户目录生成同 ID 覆盖；删除内置领域技能或其用户覆盖时，
技能会被停用，从技能库的可用列表和研究任务的技能路由中移除。内置目录本身不会删除，
可在技能库的“已停用”列表恢复；再次保存或导入同 ID 的用户技能也会恢复它。
程序内置的任务、工作流和排版技能由代码实现，在技能库中只读；其定义可导出
查看，不能作为领域技能导入。领域技能 ZIP 只包含 `manifest.json` 和
`instructions.json`，导入时会完整校验格式与字段，遇到同名用户技能须明确选择覆盖。

`manifest.json` 必填字段：`id`、`description`、`when`。可选的 `workflow` 字段支持：

- `min_tasks`、`max_tasks`：深入研究的规划步骤范围，默认 2～3，允许 1～5。
- `max_supplements`：证据评估后的最多定向补查轮次，默认 1，允许 0～3。
- `default_external_source`：`mixed` 资料模式下的外部检索类型，`academic` 或 `web`。

`instructions.json` 必填 `plan`、`draft`、`answer`、`evaluate`、`summary` 五段指令。
这五段分别作用于规划、初步判断、子任务回答、证据评估、最终总结。领域技能可以不声明
`workflow`，此时使用通用流程。任务技能（例如文献对比）与领域技能可以组合；主领域
（列表第一项）决定流程配置，最多加载两个领域的研究指令。

用户明确指定的资料范围优先。领域技能的默认检索类型不会覆盖“只用知识库”等限制。
新领域若仅改变研究方法和现有阶段的流程参数，添加这两个 JSON 文件即可；若需要新的
数据库、解析器或执行动作，仍须在程序中实现对应能力。
