# Bundled Chinese fonts

The application registers one font only when the user selects it in General Settings. The default “Follow system” option registers none. PDF pages are rendered from their own embedded fonts.

| File | Source | License |
| --- | --- | --- |
| `SourceHanSansSC-Regular.otf` | [Adobe Source Han Sans](https://github.com/adobe-fonts/source-han-sans), release branch | `LICENSE.source-han-sans.txt` |
| `SarasaUi-SC-Regular.ttf` | [Sarasa Gothic](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.43), `SarasaUiSC-TTF-1.0.43.7z` | `LICENSE.sarasa.txt` |
| `SourceHanSerifSC-Regular.otf` | [Adobe Source Han Serif](https://github.com/adobe-fonts/source-han-serif), release branch | `LICENSE.source-han-serif.txt` |
| `LXGWWenKaiScreen.ttf` | [LXGW WenKai Screen](https://github.com/lxgw/LxgwWenKai-Screen/releases/tag/v1.530) | `LICENSE.lxgw-wenkai.txt` |
